# レシートの一時保存（スマホで撮影 → PCで入力）

レシート取込画面で、撮影・選択した画像を「一時保存（PCで続きを入力）」で保存できる。PCなど別の端末で同じアカウントでログインし、画面上部の「一時保存したレシート」から「開いて入力」を押すと、その画像で読み取り・入力を続けられる。

- 一覧・表示・削除できるのは、保存したアカウント本人だけ（他のメンバー・管理者からも見えない）。サーバーはGoogle本人確認済みのセッションのuidと、Driveファイルに付けた保存者uid（appProperties `teamShiftReceiptDraft`）が一致するかを毎回確認する。閲覧ユーザーは保存できない。
- 保存先は日報で連携済みのGoogle Driveアカウントの添付保存先フォルダ（タスク添付と同じ。公開共有はしない）。タスク添付のリンクとしては開けない。
- 画像はスマホで3MB以下のJPEGに縮小してから送る（Vercelの1回の送信上限のため）。JPEG・PNGの先頭バイトを確認する。1人20件まで。
- 30日を過ぎたものは、本人が一覧を開いたときにDriveのゴミ箱へ移す。入力が終わったら「入力が終わった一時保存を削除」か一覧の「削除」でゴミ箱へ移す。
- 保存するのは画像だけ。読み取った文字・明細・基本情報は保存しない。
- Vercel Hobbyの関数数上限（12）のため、専用APIは作らず `/api/task-files` の `kind=receipt-draft` で扱う（`api/_lib/receipt-drafts.js`、`src/receiptDrafts.mjs`）。
