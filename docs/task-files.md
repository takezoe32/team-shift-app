# タスクのファイル添付

画像・動画と同じ添付欄に「ファイルを追加」を表示する。PDF、Excel（xls/xlsx）、Word（doc/docx）、PowerPoint（ppt/pptx）、テキスト、CSVに対応し、1ファイル3MB以下・1回5件まで。画像・動画の従来制限は変更しない。

- 保存前は名前・サイズと取り外しボタンを表示。文章なしのファイルだけでも保存できる。
- ファイルは日報で連携済みのGoogle Driveアカウントを使い、既存の添付保存先フォルダに保存する。公開共有やCloudinaryへの文書アップロードは行わない。
- 元の添付配列の互換形式を保ち、mediaType=file・fileIdを追加して保存・マージする。添付から画像用の圧縮・Cloudinaryアップロードを呼ばない。
- アップロード済みのFileオブジェクトは画面内で再利用し、保存を再試行するときの重複アップロードを避ける。タスクの保存前に失敗した場合の孤立ファイルの自動削除は行わない。
- APIはGoogle本人確認済みセッションとサーバー登録情報を検証し、閲覧ユーザーのアップロードを拒否する。ダウンロードは保存先・アプリ用タグを検証し、本人のファイルまたは参照可能な共有タスクに関連付いたファイルだけ許可する。
- 文書はattachmentとしてダウンロードし、ブラウザー内のHTMLなどとして実行しない。実行ファイル等は受け付けない。ウイルススキャンの実装ではない。
- 日報では元ファイルをDrive内で月別アーカイブへコピーし、リンクする。元タスクから添付を外しても日報のコピーは保持する。

検証は tests/task-files.test.mjs と既存の画像・動画・日報のテスト。実際のユーザー文書をテストでアップロードしない。

## アプリ内閲覧

- 保存済みのファイル名（閲覧する）を押すとアプリ内のダイアログで表示する。PDFは認証付き取得後の一時BlobをブラウザーのPDFビューアーで表示する。テキスト・CSVはReactのテキストとして表示し、HTMLとして解釈しない。
- Office文書は既存Google Driveファイルのプレビューを埋め込む。公開共有や変換コピーは作らない。閲覧者のGoogleアカウントにDriveのファイル閲覧権限が必要で、第三者Cookie等の端末設定によって表示できない場合もある。別画面のDrive表示と従来のダウンロードを併設する。
- プレビューメタデータのAPIもダウンロードと同じメンバー・タスク権限を検証する。Googleのアクセストークンはブラウザーに返さない。
